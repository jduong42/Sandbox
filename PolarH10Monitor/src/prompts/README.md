# Sports Science AI Prompts

This directory contains the system prompts used for the sports science AI assistant.

## Files:
- `original-prompt.md` - Original prompt used before Gemini optimization
- `gemini-optimized-prompt.md` - Gemini's improved prompt with safety protocols
- `sportsPrompts.ts` - TypeScript module with prompt templates

## Usage:
Import prompts from `sportsPrompts.ts` in the service layer.
